山中小屋 · 本地试玩版 v21
==========================

三种打开方式，任选一种：

1. 双击 Start-Game.bat（Windows，推荐）
   会弹出一个黑色窗口并自动打开浏览器。窗口是本地小服务器，玩的时候别关；
   关掉窗口就停止。不需要安装 Python 或 Node，用的是 Windows 自带的 PowerShell。
   如果浏览器没自动打开，手动访问窗口里显示的地址（一般是 http://localhost:4173/）。

2. 双击 山中小屋_离线版.html
   单个文件，所有代码和图片都在里面，拷到任何电脑上用 Chrome / Edge 打开就能玩。

3. 双击 dist\index.html
   也能直接玩，效果和第 1 种一样。

存档说明
- 对局自动保存在浏览器里。同一台电脑、同一个浏览器、同一种打开方式，下次进入会出现「继续上次对局」。
- 三种打开方式的存档互不相通（浏览器按地址区分存储）。固定用一种即可。
- 换浏览器或清理浏览器数据会丢失存档和试玩记录。试玩记录可以在开始页「试玩数据」里导出 CSV 备份。

声音
- 默认关闭。点开始页或顶栏的「声音设置」开启，可分别调音乐、环境、交互音量，并逐个试听。

macOS / Linux
- 终端运行 sh start-game.sh（需要 python3），或直接用浏览器打开离线版 HTML。

遇到问题
- 双击 bat 后报错：直接用第 2 或第 3 种方式。
- 页面空白：确认浏览器是较新的 Chrome / Edge / Firefox。
